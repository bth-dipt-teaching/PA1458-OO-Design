** Use Case: Navigate to Point
#+begin_quote
*Use Case* Navigate to Point
*Actors* Driver
*Description* Driver selects that they want to navigate to point. System displays a map. Driver selects a point. System plots a route to the point.
#+end_quote

*Main Course of Events*

| Actor                                 | System                                    |
|---------------------------------------+-------------------------------------------|
| 1. Driver selects that they           |                                           |
| want to "Navigate to Point"           |                                           |
|                                       | 2. The system selects "Navigate to Point" |
|                                       | 3. The system displays a map              |
|                                       | with the current position marked.         |
| 4. Driver selects a point on the map. |                                           |
|                                       | 5. System plots a route to the point.     |
| 6. Driver confirms the route.         |                                           |
|                                       | 7. System starts moving the robot         |
|                                       | according to the planned route.           |
|---------------------------------------+-------------------------------------------|
*Alternative Events*
5. System cannot plan a route to the point. An Error message is shown and the Driver may select another point.
